# Preferred Landscapes prezentacija

Kako objaviti na GitHub Pages:

1. Napravi nov repozitorijum na github.com (npr. preferred-landscapes)
2. Otpremi CEO sadrzaj ovog foldera (index.html, .nojekyll i folder assets) u root repozitorijuma
3. Settings > Pages > Source: Deploy from a branch > Branch: main, folder: / (root) > Save
4. Sajt ce biti na https://TVOJNALOG.github.io/preferred-landscapes/ za oko minut
